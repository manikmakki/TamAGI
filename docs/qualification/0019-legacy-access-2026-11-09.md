# Private legacy conversation access — 2026-11-09

The operator chose durable personal files and saved memories for everyday
continuity, with exact private access to retained dialogue when needed. Bulk
conversion of old conversations into native Chat/Archive is outside this rollout.

## Implementation and tested source

`expand_conversation_memory` uses a dedicated native resolver. It fetches current
canonical history first and falls back only on canonical `NotFound` to an exact
primary-owned private SQL `conversation` record. Companion scope and other
actors' records are denied. Access failures and transport errors propagate.
Missing sources retain the stored memory window; malformed message shapes fail
without shifting the original anchor or inventing message IDs.

The resolver never inserts historical threads into the active conversation
cache, writes projections or creates work, notifications or Growth recognition.
General conversation lookup and canonical admission watermarks retain their
existing behavior. Standalone expansion remains unchanged.

## Reproduction and remaining scope

Use the selected Python environment from a disposable source checkout outside
`/opt/TamAGI`, with a new output directory:

```sh
python scripts/qualify_household.py \
  --source /path/to/isolated/TamAGI --output /separate/new/legacy-access-check
```

The runner guards Python socket/DNS traffic; it is not OS confinement of arbitrary
native commands. The actual-data harness reads private checkpoint contents and
is not distributed with those contents. Generic fixtures provide the repeatable
public regression checks.

No schema conversion or transcript import is needed when primary-owned legacy
SQL conversations survive. History JSON and exported household context alone
are not read by this fallback. Full canonical shared-state recovery, historical
thread browsing/continuation and generated-tool dependency repair remain separate
work. The subsequent [Ember household activation](0019-ember-household-activation-2026-11-09.md)
records the pinned production service, cold recovery and live checks. See the
[operator action plan](../legacy-conversation-access.md).
